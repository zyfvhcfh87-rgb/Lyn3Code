# Lyn Code

Lyn Code is a fork of [T3 Code](https://github.com/pingdotgg/t3code), an "agent harness control surface" for controlling coding agents on your machine from web, desktop, and mobile clients.

Works with your subscriptions on Claude Code, Codex, Cursor, Grok Build, and OpenCode. If they're set up on your computer, Lyn Code can control them.

## "Wait, what are you selling me?"

Nothing. Lyn Code carries forward T3 Code's goal of creating the best possible development experience with agents while giving this fork room to evolve in its own direction.

We wanted something performant, remote-ready, and truly open. If we ever go the wrong direction, we want you to have everything you need to fork and build the editor that you want.

## Installation

> [!WARNING]
> Lyn Code currently supports Codex, Claude, Cursor, Grok Build and OpenCode. Install and authenticate at least one provider before use:
>
> - Codex: install [Codex CLI](https://developers.openai.com/codex/cli) and run `codex login`
> - Claude: install [Claude Code](https://claude.com/product/claude-code) and run `claude auth login`
> - Cursor: install [Cursor CLI](https://cursor.com/cli) and run `agent login`
> - Grok Build: install [Grok Build CLI](https://x.ai/cli) and run `grok login`
> - OpenCode: install [OpenCode](https://opencode.ai) and run `opencode auth login`

### Try the upstream build (install-free)

The inherited `t3` CLI still installs the upstream T3 Code build (requires Node.js 22.16+, 23.11+, or 24.10+):

```bash
npx t3@latest
```

This will launch T3 Code's backend and local web app. To run Lyn Code itself, use the source-build instructions below.

Tip: Use `npx t3@latest --help` for the full CLI reference.

### Upstream desktop app

The existing package-registry entries and upstream releases still install T3 Code, not Lyn Code:

#### Windows (`winget`)

```bash
winget install T3Tools.T3Code
```

#### macOS (Homebrew)

```bash
brew install --cask t3-code
```

#### Arch Linux (AUR)

```bash
yay -S t3code-bin
```

## If you REALLY want to contribute still.... read this first

### Install `vp`

Lyn Code uses Vite+ so you'll need to install the global `vp` command-line tool.

#### macOS / Linux

```bash
curl -fsSL https://vite.plus | bash
```

#### Windows

```bash
irm https://vite.plus/ps1 | iex
```

Checkout their getting started guide for more information: https://viteplus.dev/guide/

### Install dependencies

```bash
vp i
```
